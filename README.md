# Fl Software - Desenvolvendo Soluções

Site institucional com **portfólio vivo**: três demonstrações de sites e cardápios digitais (pizzaria, salão e oficina), com pedido, agendamento e orçamento direto no WhatsApp.

> Ajudo empresas a venderem mais com sites profissionais e cardápios digitais.
> Páginas rápidas, feitas para celular, com pedido direto no WhatsApp. Prontas em até 48 horas.

## Serviços

- Sites profissionais para empresas
- Cardápio digital estilo app, com pedido no WhatsApp e sem taxa por pedido
- Catálogo e tabela de preços para lojas e serviços

## Estrutura do projeto

```
fl-software/
├── index.html     # estrutura da página inicial
├── style.css      # estilos e animações (identidade da marca)
├── script.js      # demonstrações, carrinho e links do WhatsApp
├── logo.png       # logo da marca
├── favicon.png    # ícone da aba do navegador
└── README.md
```

## Tecnologias

HTML, CSS e JavaScript puros, sem dependências. Fontes Montserrat e DM Sans, via Google Fonts.
