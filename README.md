# Fl Software - Desenvolvendo Soluções

Site com portfólio vivo (pizzaria, salão e oficina).

## Como rodar
Abra `index.html` no navegador ou use a extensão Live Server do VS Code.

## Links das demonstrações
- `index.html#pizzaria`
- `index.html#salao`
- `index.html#oficina`

Para abrir direto a tela de pedido, use `#pizzaria-pedido`, `#salao-pedido` ou `#oficina-pedido`.

## Publicar
Suba o repositório no GitHub e ative o GitHub Pages (ou use Netlify/Vercel).
